Sashiko: Lessons from building an agentic code review system for Linux

source: linkedin — original ↗
published: 2026-11-23 · status: canonical · expanded from the original post

AI code review needs a verification budget more than a bigger prompt. Google’s Sashiko separates bug finding from verification, using per-bug deep checks.

Across seven months of Linux kernel use, Sashiko reports roughly 1,200 reviews daily and a correlation with 35% fewer 60-day follow-up fixes. Not causation.

For teams building AI reviewers, make verification a separate stage and measure false positives alongside downstream fixes—not just review throughput. https://cloud.google.com/blog/products/application-development/lessons-from-building-sashiko-an-agentic-code-review-system?utm_source=tldrit
